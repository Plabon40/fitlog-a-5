# 💪 FitLog

FitLog is a modern workout library and planning application built with Next.js. It helps users explore different workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

The application uses a clean dark-themed interface with responsive layouts designed for mobile, tablet, and desktop devices.

## ✨ Features

### 1. 🏋️ Workout Library

Browse a collection of workouts with useful information such as:

- Workout name
- Muscle groups
- Equipment
- Duration
- Calories burned
- Rating
- Workout image

The library uses a responsive grid that adapts to different screen sizes.

### 2. 📋 Workout Details

Each workout has a dedicated details page containing:

- Large workout image
- Workout description
- Muscle group tags
- Equipment
- Difficulty
- Sets and reps
- Duration
- Calories
- Rating
- Step-by-step instructions

Users can also add workouts to their daily plan or save them for later.

### 3. 📝 Today's Plan

Users can create their own daily workout plan.

The My Plan page provides:

- Today's workout list
- Exercise count
- Total workout minutes
- Total calories
- View Details action
- Mark as Done action
- Remove workout action
- Maximum five workouts for today's plan

The plan counter is also displayed in the navigation bar.

### 4. 🔖 Save Workouts

Users can save workouts for later.

Saved workouts are available from the `Saved` tab on the My Plan page, allowing users to easily access workouts they want to perform in the future.

The Saved counter is displayed in the navbar and updates when workouts are saved or removed.

### 5. 🔄 Sorting & Responsive UI

The workout list can be sorted by:

- Duration
- Calories
- Rating

The entire application is responsive and works across:

- 📱 Mobile
- 📱 Tablet
- 💻 Desktop

The navbar, hero section, workout cards, details page, My Plan page, and footer adapt to different screen sizes.

### 6. 🔔 Toast Notifications

FitLog provides feedback when users interact with workouts.

Toast notifications are shown when users:

- Add a workout to today's plan
- Save a workout
- Remove a workout
- Mark a workout as done

### 7. 💾 Persistent Workout Data

Plan and saved workout information is stored locally so that user selections can remain available after refreshing the page.

## 🛠️ Technologies Used

- **Next.js** — React framework and application routing
- **React** — Building reusable UI components
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling and UI design
- **React Icons** — Icons throughout the application
- **React Toastify** — Toast notifications
- **Next/Image** — Optimized workout images
- **LocalStorage** — Persisting plan and saved workout data
- **FitLog API** — Workout data source
